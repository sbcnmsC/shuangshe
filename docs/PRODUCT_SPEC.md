# DualCam 双摄相机

iPhone 双摄原生相机（Swift / SwiftUI，基于 `AVCaptureMultiCamSession`）。两个摄像头同时取景，实时合成为画中画或上下分屏，可同时拍照、录像。

预览显示的就是最终合成画面，**滤镜、小窗位置、画幅都是所见即所得**。整体为 iOS 风格界面。

## 界面总览

- **顶部**：闪光灯 / 定时器（关 → 3 秒 → 10 秒）/ 布局切换（画中画 ↔ 上下分屏）
- **右侧**：镜头组合，可自由设置，点一下循环切换
- **中间**：显示输出分辨率和帧率，录像时变成计时

## 小窗（画中画）

- 手指拖动小窗到任意位置，松手自动吸附到边缘 / 中线（可关闭）
- 双指在小窗上捏合缩放，或拖动小窗右下角的小把手缩放
- 点一下小窗：互换主 / 副画面
- 工具面板「小窗」页：大小、形状（圆角 / 圆形）、比例（3:4 / 1:1 / 4:3 / 9:16）、圆角、边框、透明度、复位位置
- 上下分屏时，拖动中间分割线（或面板里的滑杆）调整上下比例

## 滤镜

工具面板「滤镜」页，12 个实时滤镜：

鲜艳、暖阳、冷调、清新、电影、胶片、复古、褪色、铬黄、黑白、黑金，以及「原片」（不加滤镜）。

- 缩略图用当前画面实时生成，可调强度
- 滤镜作用在合成后的照片 / 视频上

## 参数

工具面板「参数」页：

- 变焦
- 曝光补偿
- 手动 ISO / 快门
- 白平衡（色温 + 色调）
- 手动对焦
- 锁定对焦 / 曝光

## 设置

工具面板「设置」页：

| 项目 | 选项 |
| --- | --- |
| 画幅 | 9:16 / 3:4 / 1:1 |
| 分辨率 | 720p / 1080p / 最高（最高 4K，不会超过摄像头实际像素，不做无意义的放大） |
| 帧率 | 30 / 60 fps（60 帧更吃性能，默认 30） |
| 其他开关 | 保存两路原片、弱光增亮、视频防抖、前置镜像、三分参考线 |

## 对焦 / 曝光

- 点按画面对焦并测光（点小窗就对小窗镜头对焦）
- 画面内容明显变化后自动回到连续对焦
- 点按后上下滑动，实时调整曝光补偿
- 双指捏合变焦

## 变焦

快门上方的倍率按钮（超广角显示 0.5x，长焦按实际倍率）。主 / 副镜头各自记住自己的变焦，倍率和设置流畅滑动和点按。

## 拍照 / 录像

- 底部「拍照 / 录像」切换（点击或左右滑动），中间为快门
- 设了定时器会先倒数，再点一下可取消
- 支持实况照片、视频转实况
- 录像时可随时切换布局、拖动小窗、更换滤镜，合成视频实时跟随，流畅不卡顿

## 保存

作品保存在系统「照片」App：

- 拍照：高质量 JPEG
- 录像：HEVC（H.265）
